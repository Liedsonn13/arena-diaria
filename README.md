# Arena Diária 🏆

Portal de notícias esportivas focado no cotidiano, desenvolvido com tecnologias web puras para fins acadêmicos. O projeto traz as principais atualizações de modalidades como Futebol, Basquete, Vôlei e Corrida, oferecendo navegação dinâmica, filtros interativos e total acessibilidade.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Semântica estrutural, atributos ARIA e formulários)
* **CSS3** (Grid Layout, Flexbox, Pseudo-classes estruturais e animações com `transform`)
* **JavaScript puro (Vanilla JS)** (ES6+, arrow functions, manipulação de DOM, `map`, `filter`, `reduce`, eventos e escopo)
