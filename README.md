# Arena Diaria

Portal de noticias esportivas focado no cotidiano, desenvolvido com tecnologias web puras para fins academicos. O projeto traz as principais atualizacoes de modalidades como Futebol, Basquete, Volei e Corrida, oferecendo navegacao dinamica, filtros interativos e total acessibilidade.

## Tecnologias Utilizadas

* **HTML5** (Semantica estrutural, atributos ARIA e formularios)
* **CSS3** (Grid Layout, Flexbox, Pseudo-classes estruturais e animacoes com transform)
* **JavaScript puro (Vanilla JS)** (ES6+, arrow functions, manipulacao de DOM, map, filter, reduce, eventos e escopo)
