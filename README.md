# Arena Diaria

Portal de noticias esportivas focado no cotidiano, desenvolvido com tecnologias web puras para fins academicos. O projeto apresenta as principais atualizacoes de modalidades como Futebol, Basquete, Volei e Corrida, oferecendo navegacao dinamica, filtros interativos, alternancia de temas de cores e total acessibilidade.

## Acesso Online

O projeto esta publicado e disponivel para visualizacao atraves do GitHub Pages:
- **Link do Site:** https://liedsonn13.github.io/arena-diaria/

## Tecnologias Utilizadas

* **HTML5** (Semantica estrutural, atributos ARIA, rotulos e formularios)
* **CSS3** (Grid Layout, Flexbox, variaveis de tema, pseudo-classes estruturais e animacoes com transform)
* **JavaScript puro (Vanilla JS)** (ES6+, arrow functions, manipulacao de DOM, map, filter, reduce, loops e funcoes modulares)
